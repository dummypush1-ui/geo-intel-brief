F6: complete inspectable held candidate package bytes, not runtime deployment

Default OFF MERGED_FINDER_PACKAGE_PREP_ENABLED=false. OFF precedes source/pin,
artifact/render or archive operations. ON explicitly requires F4 and F5 flags.
Input is an isolated generated root with F4's exact4source pins plus exact2
partner/sanctions candidate file hashes, a supplied original Finder commit and
baseline commit. These labels are not independently authenticated here: caller
must verify original source provenance through F3 and retain F2 last-good report.
Candidate transformed source hashes are not the upstream raw source hashes.

This closes the artifact-delivery gap: F4's full candidate index/rows/manifest/
binary proof, F5's complete safe offline render, exact generated index/offline/
SW/data and2data-source files enter one deterministic ZIP and closed manifest.
No directory traversal, arbitrary archive root, duplicate name or supplied
manifest entry. Maximum16payload entries,140MiB uncompressed and40MiB compressed.
Each source file regular/nonsymlink, hash/byte checked. Raw generated shell must
contain each of6provider/proxy constants exactly once and empty, otherwise hold
rather than stripping secrets and changing the pinned source. This exact-name
check is not a general secret detector or proof arbitrary source is safe.
Archive timestamps/permissions/order fixed; completed ZIP CRCs, exact names and
every archived file SHA256 are verified by reading the actual returned bytes.
The manifest includes source/generated/artifact hashes, explicit editions,
identity/not-bound summary, safe-render report and18runtime consumer paths.

No files are saved by the module, no output destination chosen, no runtime
edition/source/proof/pin changed, no provider/account/key/network call or public
route. Returns held report + full ZIP bytes + manifest. Report explicitly says
runtime not rebound, official freshness/legal accuracy not verified, no auto
repin or publication. Public use remains blocked by existing last-good pins.
A caller may privately save/transfer the returned review package; that grants
no public audience, production binding or Git push authority.
