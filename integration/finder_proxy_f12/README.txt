F12 - existing-proxy Finder feature bridge (default OFF)

Extends F11. Does not change the reviewed F11 candidate or authorize its push.
Flag: PUBLIC_FINDER_PROXY_FEATURES_ENABLED=false. Requires F9 selected source
and F11 data report flags. Enabling this flag alone mounts HELD UI/routes; it
cannot create an account, construct a database client, enable transport, add a
model, or grant spend/disclosure permission. No new user AI key or provider
host. Existing original source, own-key code, features and data stay preserved.

The six original controls are connected in the optional served copy:
- Classifier/search assistant: explain up to four preserved candidates. Keeps
  local search; no invented code or claim of a legally correct classification.
- Plain words: preserved code wording, not new product claims.
- Trade brief: selected snapshot rate/trade/GST evidence, dates kept.
- Paperwork: names/labels already in the source; not a live shipment checklist.
- Comparison: supplied codes and snapshot values, not a legal verdict.
- Report: separate optional snapshot-context appendix. All 21 data sections
  and the original no-key data-only report button stay available. Failed or
  held AI falls back to the data report, never to a second provider or own key.

Architecture:
- F12 noncached served-copy transform only; F8/F9 selection stays exact F11.
  F10 Save/offline report/Clear still uses the original F11 digest/bytes. No
  live bridge is cached or persisted. Keys, private news and notes are unread.
- Finder frame sends identity+feature+explicit classification question only to
  its same-origin top workspace. Parent verifies the specific frame source.
  Direct Finder and nested reference-rate wrapper routes are supported.
- Parent uses copied/extended existing account UI/client, session and CSRF.
  No auth/session request occurs on load. Password is immediately cleared from
  the form; no secret in source, storage, URLs or logs. Accounts are existing
  owner-provisioned accounts, not new provider keys. There is no signup/reset.
- Server recovers evidence from the exact bound selected source, never trusts
  client text as tariff/trade data. Gzip and literal parsing are bounded and
  do not evaluate source JS. Non-HS/IN systems use exact source-hash labels,
  explicitly not new official-edition identity proofs or freshness claims.
- FeatureBroker uses existing fixed proxy codec, authenticated principal,
  durable one-shot receipt budget and transport. No caller provider/model,
  arbitrary prompt, URL, header, evidence, notes field or destination accepted.
  Typed classifier text is the explicit exception and needs disclosure approval.
- Existing model catalog remains EMPTY. Existing proxy-plan execute=false is
  not approval. Required permission record references source-grounded spend,
  disclosure, retention and no-paid-fallback evidence, expires within an hour;
  these references do not create approval. Existing model gate still applies.
- Explicit activate() is an unselected integration point. Existing account auth
  invariant checks remain required by that code; this unit does not inspect or
  change Render workers, capacity, RAM, storage or inventory.
- One bounded dispatch, no retries, rotation, web search or fallback provider.
  Unknown outcome remains held. The old proxy may internally retry/rotate:
  proxy-call receipts are not proof of provider-attempt cost or free usage.
- Output is bounded, completed provider JSON, supplied citations only. Render
  via escaped text, not generated HTML, links or executable markup. Late UI
  results cannot replace a different code/comparison. AI never replaces rates.

Unresolved live proof, honestly HELD:
The actual proxy credential/access binding, current provider/model availability
and free entitlement, no-paid-fallback/upstream attempt behavior, disclosure
scope and proxy/provider retention. No live call or credential inspection was
performed. Empty catalog and missing permissions refuse before receipt writes.
No live readiness claim. Original account/budget provisioning remains separate.
