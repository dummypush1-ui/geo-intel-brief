PUBLIC_FINDER_SNAPSHOT_CHANGES_ENABLED=false. Requires selected F9 source.
Accepts a second exact internal F8 Binding via finder_comparison_baseline.
No baseline means comparison unavailable, never assumed unchanged. No raw
path/hash/request/env baseline injection, source acquisition, refresh, secret,
provider, user notes, saved watch state or localStorage. Existing watch alerts
and original Finder stay intact. F11/F12 candidates remain unchanged.

Compares exact raw source wording, listed duty, GST source entries and presence
by system/code. Last source row matches original Finder key handling; duplicate
identities are disclosed. Empty listed duty is shown as not listed, not zero.
Source build labels, revision and full package/offline SHA256s remain visible.
They prove supplied artifact identity, not official dates, law or currentness.

Original Finder linkage algorithm uses code's first six digits for other
systems, exact selected national target for own system; chain2/4/6/8 and national
extensions. F13 compares those targets, chains, counts and full extension code
membership digest. UI shows at most8extension codes per system and says when
sample incomplete. It is NOT legal equivalence or a complete code-level delta
list. A changed digest beyond8 is detected even if sample/count stay equal.
Missing rows/links are snapshot observations, not deletions or delisting proof.
No currency, timing, qualified-rate, shipment advice or clearance claims.

Manual read-only page/API only. No automatic fetch, timer, AI or writes.
Off routes denied; exact origin, identity and duplicate query guards. HEAD is
metadata only. Drift in either F8 source refuses with no change claim. CSP and
no-store apply. Rendering uses textContent, including source wording/hashes.

Implementation uses the existing nonexecuting source-literal helper from F12;
it does not enable F12 or ask for AI keys. F8 currently covers only the two
source file refresh chain shapes it verifies; arbitrary or official upstream
archives do not become acceptable baselines through this feature.
